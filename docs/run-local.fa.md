# اجرای برنامه روی کامپیوتر خودتان (ویندوز)

یک فرمان همه‌چیز را آماده و اجرا می‌کند: سرور پژوهش (API)، سرویس نگاه، اپ شرکت‌کننده و پنل پژوهشگر. همه‌چیز فقط روی همین کامپیوتر (127.0.0.1) باز می‌شود.

## پیش‌نیازها (یک‌بار)

| برنامه | نسخه | نکته |
|---|---|---|
| Git | هر نسخهٔ جدید | https://git-scm.com/download/win |
| Python | 3.11 یا بالاتر | هنگام نصب گزینهٔ «Add python.exe to PATH» را بزنید |
| Flutter | 3.47 یا بالاتر (Dart 3.13.4) | اگر قدیمی است: `flutter upgrade` |
| Chrome یا Edge | – | برای دوربین و اپ‌ها |
| وب‌کم | – | برای جلسهٔ واقعی |

## گرفتن کد (یک‌بار)

```powershell
cd D:\Work
git clone https://github.com/arashghazi/eyetracking.git eyeTracking
```

اگر پوشهٔ `D:\Work\eyeTracking` از قبل هست ولی کلون git نیست، اول نامش را عوض کنید (مثلاً `eyeTracking-old`) و بعد کلون کنید. مخزن خصوصی است، پس بار اول Git پنجرهٔ ورود GitHub را باز می‌کند.

## اجرا

روی `scripts\run-local.cmd` دوبار کلیک کنید، یا:

```powershell
D:\Work\eyeTracking\scripts\run-local.cmd
```

اجرای اول چند دقیقه طول می‌کشد (محیط Python، بسته‌ها، ساخت دو اپ وب). اجراهای بعدی فقط کد تازه را با `git pull` می‌گیرند و اگر کد عوض شده باشد دوباره می‌سازند. در پایان، اسکریپت این‌ها را چاپ می‌کند و دو اپ را در مرورگر باز می‌کند:

- **پنل پژوهشگر** در http://localhost:5173 با حساب مدیر و حساب پژوهشگر نمونه.
- **اپ شرکت‌کننده** در http://localhost:8080 با یک شرکت‌کنندهٔ نمونهٔ آماده (کد P-001، هر دو مسیر تمرین واگذار شده).
- **یک لینک دعوت تازه** تا روند ثبت‌نام را خودتان امتحان کنید.

رمزها تصادفی ساخته می‌شوند و در `D:\Work\eyetracking-local\local-accounts.json` می‌مانند. پایگاه داده، رسانه‌ها و لاگ‌ها هم در همان پوشه‌اند، بیرون از مخزن.

توقف همهٔ سرورها:

```powershell
D:\Work\eyeTracking\scripts\stop-local.cmd
```

## اندازه‌گیری واقعی با L2CS

بدون وزن‌ها، سرویس نگاه «synthetic» است: دقتی ندارد و نتیجهٔ سطح چشم را مسدود نگه می‌دارد. برای آزمون واقعی:

1. وزن‌های منتشرشدهٔ L2CS-Net (فایل `L2CSNet_gaze360.pkl`) را از بخش مدل‌های ازپیش‌آموزش‌دیدهٔ پروژهٔ L2CS-Net در GitHub (`Ahmednull/L2CS-Net`) دانلود کنید. مجوز داده‌های Gaze360 را برای استفادهٔ پژوهشی بررسی کنید.
2. اجرا کنید:

```powershell
D:\Work\eyeTracking\scripts\run-local.cmd -Model l2cs -Weights D:\Models\L2CSNet_gaze360.pkl
```

بار اول PyTorch نصب می‌شود (دانلود بزرگ). اگر کارت گرافیک NVIDIA با CUDA دارید، `-Device cuda` را اضافه کنید.

## گزینه‌های دیگر

| گزینه | کار |
|---|---|
| `-Rebuild` | ساخت دوبارهٔ اپ‌های وب |
| `-NoPull` | بدون گرفتن کد تازه |
| `-NoBrowser` | مرورگر را باز نکند |
| `-NoDemo` | در اجرای اول مطالعهٔ نمونه نسازد |
| `-DataDir <پوشه>` | پوشهٔ دیگری برای داده |
| `-ApiPort`، `-GazePort`، `-ParticipantPort`، `-AdminPort` | اگر درگاهی اشغال است |

ارائه‌دهندهٔ هوش مصنوعی به‌طور پیش‌فرض ساختگی و رایگان است. برای Anthropic یا HeyGen کلیدها را در `backend\.env` بگذارید (نمونه در `backend\.env.example`). این فایل هرگز کامیت نمی‌شود.

## اگر خطا داد

- اسکریپت ۲۵ خط آخر لاگ را نشان می‌دهد. لاگ کامل در `D:\Work\eyetracking-local\logs` است.
- «Port … is already used»: برنامهٔ دیگری آن درگاه را گرفته است. آن را ببندید یا درگاه دیگری بدهید.
- «Python 3.11 or newer was not found»: Python را از python.org نصب کنید، نه از Microsoft Store، و PATH را تیک بزنید.
- برای شروع از صفر، سرورها را متوقف و پوشهٔ `D:\Work\eyetracking-local` را حذف کنید.

این اجرا فقط برای آزمون محلی است. دادهٔ شرکت‌کنندهٔ واقعی را در آن وارد نکنید.
