## Choices
- Roles follow the existing rule: `canEdit` is everyone except analysts (administrators act as researchers in the UI and the server decides: a non-member gets 403 and the message is shown as written). Analysts: no live monitor (the server refuses it, the section says so), no import, no save, no observation form, no debrief editing; they review thresholds, compare, read the report, history, debrief form and observations.
- Live: the observation form sits next to the panel (below it under 1000 px). "Use current session time" sends `last_sample_t_ms` and is disabled while there is no sample. Synthetic sessions get a warning box and grey bars. Switching to another section or another main tab stops the polling; coming back reads at once.
- Thresholds: Save is enabled only for a reviewed candidate that still matches the fields (changing a field marks the result stale; toggling "Include synthetic" clears it). The dialog lists label, old -> new for every changed value and needs at least 10 characters (spaces do not count). The 422 text stays in the dialog.
- Tracker comparison: all client checks are light; the server has the last word (a missing column is its 422 text, shown as written). Caveats are a warning box above the numbers. Shares the server reports as null show as dashes, not 0 %.
- Debrief: Save sends `questions` only when they changed (plus `enabled`), so the switch alone never makes a version; the notice says when a version was created and that answers keep theirs. The first save of an unsaved form stores the suggested questions as version 1.
- The section switcher is a wrapping row of choice chips, not a segmented button: five labels do not fit a phone or an 800 px window. Tables scroll sideways.
- Participants are only ever shown as research codes. Dates use `formatTimestamp` (UTC), session time `formatClockMs`.

## Missing
- Seen in a headless browser against the backend (docs/features/step6-e2e.md): live monitor, observation, threshold review and save with rationale, history, tracker import through the real file dialog and comparison, report and CSV, question editor. `PlatformMediaPicker` reads the whole file into memory; the server limit is 150 MB.
- Switching section discards the Live panel (by design, it stops polling) but keeps Thresholds, Tracker, Report and Questions state; the Report is not refreshed unless "Refresh" is pressed.
- The Measurement settings form does not edit the two quality thresholds (only the threshold review saves them); "calibration_points" and "allow_continue_without_validation" cannot be tried in a review (the server says they apply to new sessions only).
- The session-detail observation form has no session-time field (a note there is about the whole session).
- DataRow keys are not part of the widget tree, so table tests read rows from the `DataTable` widget.
