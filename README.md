## وضعیت

مرحلهٔ طراحی. ساخت نرم‌افزار، اتصال به سرویس پولی و آغاز پژوهش با شرکت‌کننده هنوز شروع نشده است.
تصمیم‌های باز در صفحهٔ ۷ سند طراحی فهرست شده‌اند.

## پشتهٔ پیشنهادی

Flutter برای هر دو برنامه، سرویس Python / FastAPI برای حساب، جلسه و داده، و مدل نگاه در پردازش مستقل.
