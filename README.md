# EyeTracking Practice

دو برنامهٔ انگلیسی برای آزمون و تمرین نگاه (تماس چشمی) با یک بستر پژوهشی مشترک:
اپ شرکت‌کننده (Participant App) و پنل پژوهشگر (Research Admin).

## وضعیت

گام‌های ۱ تا ۷ برنامهٔ ساخت انجام شده‌اند: حساب و رضایت، جلسه و اندازه‌گیری با اعتبارسنجی ناحیه‌ای، دو مسیر تمرین با پروتکل نسخه‌دار و کتابخانهٔ محتوا، پنل پژوهش با بازپخش، تحلیل، خروجی کدگذاری‌شده، ثبت دسترسی و قواعد حذف داده، تولید محتوای هوش مصنوعی (متن و ویدئو) با صف کار، سقف هزینه و بازبینی اجباری پژوهشگر، و ابزارهای پایلوت تحت‌نظارت (پایش زنده، یادداشت ناظر، آستانه‌های نسخه‌دار با بازبینی پیش از ذخیره، پرسش‌های پس از جلسه، مقایسه با ردیاب پژوهشی و گزارش پایلوت؛ روال اجرا در `docs/pilot/pilot-runbook.md`)، و گفت‌وگوی زنده با آواتار به‌عنوان مسیر سوم با قواعد محافظ سمت سرور و ارائه‌دهنده‌های توسعه (آواتار جریانی واقعی هنوز انتخاب و وصل نشده است: `docs/design/live-avatar-vendor-decision.fa.md`)؛ خودِ پایلوت با شرکت‌کننده هنوز انجام نشده است؛ هنوز هیچ فراخوانی زندهٔ Anthropic یا HeyGen انجام نشده است. آزمون با وب‌کم واقعی و وزن‌های L2CS هنوز روی PC انجام نشده است. وضعیت کوتاه در `docs/current-state.md` و یادداشت هر گام در `docs/features/`.
اتصال به سرویس پولی و آغاز پژوهش با شرکت‌کننده هنوز شروع نشده است. تصمیم‌های باز در صفحهٔ ۷ سند طراحی فهرست شده‌اند.

## اجرا روی کامپیوتر خودتان

روی ویندوز `scripts\run-local.cmd` را اجرا کنید. راهنمای کامل، شامل پیش‌نیازها و اندازه‌گیری واقعی با L2CS، در `docs/run-local.fa.md` است.

## ساختار مخزن

| مسیر | محتوا |
|---|---|
| `backend-dotnet/` | سرور پژوهش به C# (ASP.NET Core، EF Core، SQL Server) با همان API؛ جایگزین سرویس پایتون (`backend-dotnet/README.md`) |
| `backend/` | سرویس Python / FastAPI (مرجع تا کنار گذاشته شود)، سرویس نگاه (`eyetracking/gaze`) و آزمون‌های HTTP مشترک هر دو بک‌اند (`backend/README.md`) |
| `apps/participant/` | اپ شرکت‌کننده (Flutter) |
| `apps/admin/` | پنل پژوهشگر (Flutter) |
| `packages/core/` | بستهٔ مشترک Flutter: تم، کلاینت API، مدل‌ها |
| `scripts/` | اجرای محلی روی ویندوز (`run-local.cmd`، `stop-local.cmd`) و دادهٔ نمونه |
| `docs/` | سند طراحی، پژوهش، وضعیت فعلی و یادداشت گام‌ها |

قواعد توسعه در `AGENTS.md` آمده است.
